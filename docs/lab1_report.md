# Отчёт по лабораторной работе № 1

## 1. Цель работы

Подготовить основу Python-проекта: настроить структуру пакета, управление зависимостями, конфигурацию приложения,
журналирование, интерфейс командной строки, автоматические проверки качества кода и тестирование.

## 2. Структура проекта

Для проекта использована структура `src-layout`. Исходный код расположен в `src/research_graph/`, тесты — в `tests/`.

Основные файлы и каталоги:

- `src/research_graph/config.py` — настройки приложения и их валидация.
- `src/research_graph/logging_setup.py` — настройка журналирования.
- `src/research_graph/cli.py` — интерфейс командной строки.
- `tests/` — автоматические тесты.
- `pyproject.toml` — метаданные проекта, зависимости и настройки инструментов.
- `uv.lock` — фиксация версий зависимостей.
- `.pre-commit-config.yaml` — проверки перед созданием коммита.
- `.github/workflows/ci.yml` — конфигурация автоматических проверок GitHub Actions.

Версия Python — 3.12. Для управления зависимостями используется `uv`.

## 3. Конфигурация приложения

Настройки реализованы с помощью `pydantic-settings`. Предусмотрена загрузка параметров из переменных окружения с
префиксом `RG_`.

Реализованы следующие параметры: токен GitHub, каталог данных, уровень журналирования, тайм-аут запросов и максимальное
количество параллельных операций. Для тайм-аута и количества параллельных операций заданы ограничения допустимых
значений.

Токен GitHub скрыт при отображении объекта настроек. Команда проверки конфигурации не выводит значение токена.

## 4. Интерфейс командной строки и журналирование

С помощью Typer реализованы команды:

- `rg version` — вывод версии приложения.
- `rg check-config` — проверка конфигурации и вывод основных параметров без раскрытия секретов.

Для журналирования используется стандартный модуль Python `logging`. Формат сообщений включает время, уровень важности,
имя регистратора и текст сообщения.

## 5. Проверка качества кода и тестирование

Для проверки проекта настроены Ruff, Mypy, Pytest и Pre-commit. Тесты проверяют значения настроек по умолчанию, загрузку
параметров из переменных окружения, валидацию ограничений, скрытие токена и работу команд CLI.

Результаты локальных проверок:

| Проверка              | Результат                          |
|-----------------------|------------------------------------|
| Ruff — проверка кода  | Успешно                            |
| Ruff — форматирование | Успешно                            |
| Mypy                  | Ошибок не обнаружено               |
| Pre-commit            | Все применимые проверки пройдены   |
| Pytest                | 8 тестов пройдены                  |
| Покрытие тестами      | 84,31% при требовании не менее 70% |

## 6. Непрерывная интеграция

Настроен GitHub Actions. При отправке изменений в репозиторий и создании pull request запускаются проверки
форматирования, стиля кода, типов и тестов.

После публикации конфигурации CI запуск GitHub Actions завершился успешно.

## 7. Контроль версий

Проект размещён в GitHub: [AI_Jobs_Research](https://github.com/NRina4/AI_Jobs_Research).

Для контроля версий используется Git. Настроены удалённый репозиторий `origin` и ветка `master`. Созданы коммиты с
настройкой структуры проекта и добавлением CI. Служебные файлы, включая виртуальное окружение и результаты покрытия
тестами, исключены из отслеживания с помощью `.gitignore`.

автоматическими тестами и инструментами контроля качества кода. Настроен GitHub Actions, успешный запуск которого
подтверждён. Локальные проверки пройдены, а покрытие кода тестами составляет 84,31%, что превышает установленный порог в
