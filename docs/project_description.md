# Описание проекта

## Предметная область

Система **AI Jobs Research** предназначена для хранения и анализа данных о вакансиях в сфере искусственного интеллекта на основе набора данных Global AI Jobs 2026. Предметная область включает компании-работодателей, страны и континенты, должности, специализации и отрасли ИИ, типы занятости, требования к сертификации, навыки и сами вакансии с условиями оплаты, опытом, метриками рынка и сроками публикации.

## Назначение системы

Система позволяет:
- импортировать и хранить данные о вакансиях из CSV в реляционной БД;
- выполнять CRUD-операции над вакансиями через REST API;
- искать, фильтровать, сортировать и постранично просматривать вакансии;
- получать аналитические показатели по зарплатам, навыкам и спросу;
- выполнять бизнес-операции сравнения вакансий и поиска похожих вакансий;
- работать с данными через простой веб-интерфейс.

## Основные сущности

- **Continents / Countries** — география размещения вакансий (страна относится к континенту).
- **Companies** — компании, публикующие вакансии.
- **Job titles** — названия должностей.
- **Specializations** — специализации в области ИИ.
- **Industries** — отрасли компаний.
- **Employment types** — типы занятости.
- **Certification requirements** — требования к сертификациям.
- **Skills** — навыки, требуемые в вакансиях.
- **Vacancies** — основная сущность с зарплатой, опытом, датами, метриками и ссылками на справочники.
- **Vacancy skills** — ассоциативная таблица связи «многие-ко-многим» между вакансиями и навыками.

## Пользовательский сценарий

Пользователь может просматривать и фильтровать каталог вакансий, создавать и редактировать записи, сравнивать выбранные вакансии по зарплатным условиям, находить похожие вакансии и анализировать агрегированную статистику рынка труда в ИИ.
